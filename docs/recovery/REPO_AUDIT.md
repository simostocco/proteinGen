## Mathematical Implementation

Normalization:

- README and `compute_train_statistics.py` describe train-only percentile scaling from valid finite non-negative upper-triangular distances. The actual implementation is missing with `data.statistics`.
- Training loads `normalization_file` JSON and relies on `DistanceMapDataset` to provide normalized matrices; dataset implementation missing.

Forward diffusion:

For timestep `t` and clean normalized matrix `x0`:

```text
x_t = sqrt(alpha_bar_t) * x0 + sqrt(1 - alpha_bar_t) * epsilon
```

`epsilon` is symmetric Gaussian noise sampled only for valid off-diagonal positions, mirrored to the lower triangle, zero diagonal, and masked.

Epsilon target:

```text
target = epsilon
```

v target:

```text
v = sqrt(alpha_bar_t) * epsilon - sqrt(1 - alpha_bar_t) * x0
```

v conversions:

```text
x0_hat      = sqrt(alpha_bar_t) * x_t - sqrt(1 - alpha_bar_t) * v_hat
epsilon_hat = sqrt(1 - alpha_bar_t) * x_t + sqrt(alpha_bar_t) * v_hat
```

Epsilon conversion:

```text
epsilon_hat = model_output
x0_hat = (x_t - sqrt(1 - alpha_bar_t) * epsilon_hat) / sqrt(alpha_bar_t)
```

Reverse posterior mean:

```text
coef_x0 = beta_t * sqrt(alpha_bar_{t-1}) / (1 - alpha_bar_t)
coef_xt = sqrt(alpha_t) * (1 - alpha_bar_{t-1}) / (1 - alpha_bar_t)
mu = coef_x0 * x0_hat + coef_xt * x_t
```

Posterior variance:

```text
posterior_variance = beta_t * (1 - alpha_bar_{t-1}) / (1 - alpha_bar_t)
```

Masked training loss:

For each protein independently, valid entries are the upper-triangular off-diagonal entries whose pair mask is true. The loss is:

```text
loss_i = sum_valid((target_i - prediction_i)^2) / max(valid_pair_count_i, 1)
loss = mean_i(loss_i)
```

This prevents long proteins from dominating solely because they have `O(N^2)` pairs.

U-Net tensor shapes and channels:

- Model input tensors: `noisy_distance [B,1,N_padded,N_padded]`, `sequence_separation [B,1,N_padded,N_padded]`, `pair_mask [B,1,N_padded,N_padded]`.
- Concatenated convolution input: `[B,3,N_padded,N_padded]`.
- Model output: `[B,1,N_padded,N_padded]`.
- `N_padded` must be divisible by `model.downsample_factor = 2 ** (len(channel_multipliers) - 1)`.
- Output is symmetrized, diagonal-zeroed, and multiplied by `pair_mask`.
- Sequence-separation semantics are documented as `abs(i-j) / max(N-1, 1)`; helper implementation missing.
- Length embedding is continuous: `log(length) / log(max_length)` passed through `Linear -> SiLU -> Linear`. It is not a discrete embedding lookup.
