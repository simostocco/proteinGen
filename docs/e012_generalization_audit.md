# E012 V3 fixed-checkpoint generalization audit

Evaluation-only retrospective audit based on immutable continuation result `8d1a265f19c02bf2a0ec6734d30aa02e90e6cc6b`. Checkpoints 2000, 5000, 7500, 10000 are fixed; none is selected for deployment or relabeled. No optimizer, backward, scheduler change, checkpoint save, generation, package installation or corpus acquisition is authorized.

One TRAIN panel is frozen before inference: 2048 distinct identities, length quotas 410/410/410/409/409 matching the fixed primary and independent held-out panels. Rank each stratum by SHA256 of UTF8 `E012-V3:13012:` plus sample ID, tie-break by ID. Membership and deterministic target positions are recorded and hashed. Selection uses no performance or family information. TRAIN exposure counts at each checkpoint are descriptive; membership in TRAIN does not mean an identity had already been presented at update 2000.

All three panels use the unmodified historical `likelihood()` evaluator: model.eval(), no_grad(), BF16 forward with float32 log-softmax, batch16, full24 output, canonical next-residue targets, same padding and requested-length conditioning. Equal-protein CE is primary; token-weighted CE, both perplexities, top1/top3, the five historical length strata and ten historical relative-position deciles are also reported. Confidence and canonical-class calibration are measured in a second identical forward and checked against exact evaluator CE. Canonical probabilities are not renormalized; special-token mass is reported.

The original composition-preserving prefix shuffle and last1/4/8/16/32/64/full protocol is reused. Tensor-identical CPU construction followed by bulk CUDA transfers avoids per-residue device writes; tests establish constructor parity. The fixed historical held-out context records at 2000/5000/10000 are reused with protected hashes. TRAIN contexts and all three panels at7500 are evaluated now. No scientific gate or historical classification is changed.

Same-batch reconstruction uses saved sampler/cursor and verifies exact identity lists against telemetry. At2000/5000/7500, evaluate the exact next historical batch from incoming checkpoint weights/RNG. At10000 reconstruct the final historical batch from sampler7500; final LR=0 preserves the pre-step parameters, but incoming dropout RNG is unavailable, so a new draw from saved outgoing RNG is explicitly distinguished. Historical train-mode sequence_mean computation is reproduced under no_grad without optimization; differences from original grad-enabled kernels/RNG consumption are measured, not assumed absent.

Original logged CE is instantaneous train-mode, dropout-active equal-protein CE over one natural-distribution 64-protein optimizer batch, computed before optimization. Each unequal microbatch mean is weighted by n/64. It is neither token-weighted nor a rolling or epoch average. Length distributions differ from the stratified fixed panels. Its loss formula matches evaluation, but the raw logged values are not directly comparable to fixed eval-mode panels.

Bootstrap intervals use 10000 identity resamples, seed12112. Matched checkpoint changes are paired by identity. TRAIN versus held-out population gaps use independent identity resampling of each disjoint panel; identities cannot be paired across different proteins. GEN-A/B/C/D/E interpretation follows the user's qualitative definitions, with explicit effect sizes and no invented numerical threshold. A broad expanding matched gap supports over-specialization/generalization as a bottleneck; corpus size alone is not established causally. No larger-model recommendation follows automatically.

Runtime guards block optimizer construction, optimizer steps, Tensor.backward and torch.save. Checkpoint file hashes and model-state fingerprints are verified before/after. Other research worktrees are read-only; GPU use requires ownership inspection. Large per-identity output records stay ignored/local; only new V3 source, protocol and compact audit results are published.
