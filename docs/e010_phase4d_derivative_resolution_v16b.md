# V16B fixed-state derivative resolution audit

This numerical audit uses only the exact historical synthetic lengths 12/32/500, current Pg, target X, mask, fixed sinusoidal correction state and three cosine directions from V16A. No optimization, real-panel example, teacher-quality metric or solver continuation is used. V16A remains TEACH-E and unchanged.

The historical nine checks are three deterministic phases (0, .7, 1.3) crossed with epsilon (1e-6,1e-5,1e-4). Each checks a scalar normalized local objective and the vector of historical safety constraints, requiring every component to meet absolute tolerance 1e-8 plus relative tolerance 1e-5 times absolute analytic derivative. The vector includes aligned RMSD, continuous chirality, signed no-new-inversion, unsigned assessability, frame assessability and bond assessability. The report retains every family and the worst tolerance-normalized component; full component data can be regenerated and lives in ignored numerical-array outputs with versioned hashes.

The complete 13-value logarithmic grid in the config is frozen before execution; no values are dropped. Every direction uses identical grid/half-grid evaluations and Richardson extrapolation. Record full-Jacobian directional derivatives, independent direct autograd JVP through the full geometry, and scalar reverse-autograd contractions for each constraint family. Analytic path consistency is checked to 1e-12 +1e-10 absolute/relative tolerance; the historical finite-difference tolerances are never altered.

Physical perturbations are 0.10*h*d at eligible coordinates; endpoints are zero. Record intended maximum/RMS vector norms across masked residues and actual stored coordinate changes. Exact normalized z and coordinate hashes are created now; V16A did not save those particular hashes, so verify recovery through bitwise reproduction of every available historical derivative comparison instead of claiming a historical hash exists.

Compare centered numerators with function magnitude and machine-epsilon local scales; report error, sign agreement and reliable digits estimated from relative error (zero/tiny derivatives require absolute-error interpretation). Stable windows require every objective/constraint component to meet the unchanged tolerance. Richardson half-grid data is diagnostic only and never replaces the derivative. A grid ending at 1e-4 may show no truncation-dominated regime; if so report that limit without extending it after inspection.

The preregistered proposed future rule is fixed h=1e-4 in dimensionless z units: physically tiny eligible displacements, but many coordinate ULPs at length500's ~1000 Å coordinate scale. It is a proposal only, contingent on audit support; do not apply it to V16A or launch the teacher panel. All original scientific settings, bounds, constraints, tolerances and artifacts remain unchanged.
