# Sequential privileged teacher V16A

This is a reproducible policy trajectory, not a globally optimal oracle. The teacher receives target X; a later neural student will receive current geometry and will **not** receive X. Historical results and implementations are immutable.

Each of 60 fixed trajectories starts at frozen Pg. For each of 16 sequential steps, optimize only one 3N-dimensional Cartesian action, zero-initialized, with radius 0.10 Å. Current eligibility is recomputed; ineligible corrections are exactly zero. The only objective is the historical mean i+1/i+2/i+3 endpoint-masked distance MSE, with positive constant normalization by original Pg local MSE. No weighted auxiliary terms or joint future actions exist.

CPU float64 SciPy SLSQP uses analytic objective/vector constraint Jacobians, maxiter=1000, ftol=1e-12. Original Pg owns all safety baselines and quartet classifications throughout: aligned RMSD <=1.01 baseline, continuous chirality <=baseline, exact signed/unsigned quartet and assessability inequalities from V9. Historical normalized global feasibility tolerance 1e-8 and exact nonpositive quartet constraints remain unchanged. Every candidate additionally passes evaluator no-new-inversion/assessability, finite and noncollapse checks.

Every objective trial, major callback and final iterate is considered after deterministic closed-ball projection. Already feasible actions remain bitwise unchanged. Outside actions are radially projected; if NumPy float64 norm still exceeds 0.10, apply successive nextafter(1,0) uniform factors until the first feasible stored vector. This guard is part of candidate selection, never a chirality/RMSD repair. Recompute every nonlinear safety quantity after projection. Record radial projection and inward ULP adjustments separately.

Keep the feasible candidate with lowest local loss; ties prefer smaller Frobenius action norm, earlier iteration, then earlier evaluation. Zero is included. If best improvement is not greater than 1e-6 of original Pg local MSE, accept zero. This materiality comes unchanged from V9B loss-sensitivity analysis, not the 5% scientific target. Solver success is telemetry; no stationarity/global-optimality claim is required for a safe useful teacher action.

Before any panel solve, validate derivatives and all 60 zero-state baselines; run historical synthetic one-step lengths 12/32/500. The length-500 solve must remain under 4 GiB peak RSS and 3600 seconds. No solver fallback or settings tuning. Process calibration uses eight identical deterministic length-32 preflight jobs at 1/2/4/8 workers, subject to CPU/RAM limits; each worker uses one thread. Choose fastest safe measured throughput before scientific execution. Steps within a trajectory stay sequential. Repeated synthetic solves validate deterministic process execution, never select scientific outcomes.
