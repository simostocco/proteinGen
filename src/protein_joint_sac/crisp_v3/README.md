# CRISP V3 independent training system

J1 is permanently frozen and held outside System. Seven independent encoders provide residual joint actions, twin low/high Q values and policy-indexed reachability. Development/research/large profiles are explicit; target copies are non-trainable.

Use scripts/e017_v3/train.py --config configs/e017_v3/research_supervised.json for a dry-run. --execute additionally requires a separately approved config/source/reference-specific authorization receipt and adequate D: checkpoint reserve. No substantive training is authorized by this source publication. Later stages require a full initialization checkpoint. See the evidence-root FINAL_E017_CRISP_V3_ENGINEERING_HANDOFF.md for measured tests, equations, data and limitations.

Engineering scripts publish new evidence without replacing successful results. Intermediate failed fixtures and their checkpoints remain preserved. No AlphaFold/biological reward, no new dataset split, no J1 optimizer membership.
